# 安全、隐私与权限

## 1. 安全目标

- 用户薪资、日历事项、截图、录屏和 API Key 默认只在本机处理；
- 仅在用户主动触发时申请或使用高敏感系统权限；
- 权限拒绝不应导致崩溃、死循环或不可恢复状态；
- 日志、提交、测试数据和发布包不得泄露敏感信息；
- 公开发布前完成签名、公证、依赖和许可证审核。

## 2. 数据分类

| 等级 | 数据 | 要求 |
|---|---|---|
| 高敏感 | API Key、截图、录屏、麦克风音频 | 最小采集、最小权限、禁止日志明文、用户可删除 |
| 敏感 | 薪资、工作时间、请假/倒班、日程与待办正文 | 本地存储、限制访问、备份与共享前脱敏 |
| 一般 | 主题、颜色、快捷键、窗口偏好 | 本地持久化，可重置 |
| 公开 | 产品文档、版本号、许可证文本 | 可进入仓库与发行包 |

## 3. macOS 权限

| 权限 | 使用场景 | 最小化策略 |
|---|---|---|
| 屏幕与系统音频录制 | 截图、录屏 | 仅用户点击或快捷键触发；拒绝时提示设置路径 |
| 麦克风 | 录制麦克风音频 | 仅录屏需要时使用；不后台常驻采集 |
| 辅助功能/输入监听 | 全局快捷键或特定交互 | 仅功能确实需要时申请，不以宽泛权限替代正确实现 |
| 文件写入 | 保存截图、录屏和应用数据 | 只写应用支持目录及用户可理解的媒体目录 |

权限用途文案必须和实际行为一致，新增采集能力时同步更新 `Info.plist`、用户手册和威胁模型。

## 4. API Key

### 当前状态

OpenAI、Gemini、Claude、Groq 等 API Key 目前由应用设置页录入，并保存在 UserDefaults。UserDefaults 不是专用秘密存储，因此这是已知安全技术债。

### 目标状态

- 使用 macOS Keychain 保存、读取、更新和删除密钥；
- UI 只显示掩码，不提供完整回显；
- 复制、日志、崩溃报告和分析事件不包含密钥；
- 切换服务商或清除配置时删除不再使用的 Keychain 项；
- 网络请求只发送到用户选择的服务商 HTTPS 端点。

用户不知道自己的 OpenAI API Key 时，应在 OpenAI Platform 自行创建；任何维护者都无法读取或代替生成用户账户中的 Key。

## 5. 网络边界

实时收益、工作日历、截图与录屏不需要云端即可工作。AI 助手只有在用户配置第三方模型并发起请求时才进行网络访问。

当前 `NSAllowsArbitraryLoads = true` 扩大了网络攻击面。公开发布前应删除全局例外，按实际 HTTPS 域名配置最小 ATS 例外，并验证重定向、证书错误和超时行为。

## 6. 本地文件保护

- 应用数据放在 `~/Library/Application Support/Atoll`；
- 截图与录屏放在用户明确可见的 Pictures/Movies 子目录；
- 写入采用可恢复策略，避免半写入破坏 JSON；
- 删除高敏感媒体应由用户明确触发；
- 不应把用户真实数据复制到测试夹具或 Git 仓库；
- 备份文件继承同等级保护要求。

## 7. 安全开发要求

- 合并前执行秘密扫描和依赖审查；
- 外部输入、JSON、文件名、URL 和模型响应均按不可信处理；
- 不使用模型输出直接执行 shell、AppleScript 或文件删除；
- 全局快捷键注册检查冲突并提供撤销；
- 截图/录屏有明确开始、进行中、停止和失败状态；
- 敏感设置变更不记录明文值。

## 8. 事件响应

发现密钥泄露时立即撤销并重新生成，清理仓库历史和构建产物，确认日志与备份是否包含泄露内容。发现录屏、截图或日程隐私事件时先停止相关功能和分发，保存脱敏证据，评估影响，修复并回归后再恢复发布。

## 9. 公开发布门槛

- API Key 迁移到 Keychain；
- ATS 全局放行被移除；
- Developer ID 签名、公证与验证通过；
- 权限与隐私声明经实机验证；
- 威胁模型和依赖许可证完成复核；
- 无高危未接受风险。
