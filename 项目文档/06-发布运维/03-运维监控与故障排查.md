# 运维监控与故障排查

## 1. 可观测性原则

Atoll 是本地 macOS 应用，当前没有服务端监控。排查依赖应用状态、系统日志、输出文件和可复现步骤。日志不得记录 API Key、完整日程正文、截图内容、薪资明文或录音内容。

## 2. 基础信息采集

每次问题至少记录：

- 应用版本、分支和提交；
- Mac 型号、macOS 版本、是否实体刘海和显示器情况；
- 复现步骤、发生时间、预期和实际结果；
- 权限状态、剩余磁盘空间、输出目录；
- 是否为首次安装、覆盖安装或升级。

## 3. 日志查看

实时查看 Atoll 进程日志：

```bash
log stream --style compact --predicate 'process == "Atoll"'
```

查看最近 15 分钟：

```bash
log show --last 15m --style compact --predicate 'process == "Atoll"'
```

共享日志前先检查并移除个人数据与敏感配置。

## 4. 常见故障

| 现象 | 优先检查 | 处理 |
|---|---|---|
| 应用打不开 | 签名、系统日志、旧进程 | 验证签名，结束残留进程，重新安装可信构建 |
| 刘海仍是旧版本 | 实际应用路径、进程、提交 | 退出旧进程，核对 `/Applications/Atoll.app` 修改时间并重装 |
| 金额/进度不刷新 | 设置是否保存、工作日与时间区间 | 保存后重开 Home；检查当天覆盖与午休配置 |
| 四位金额遮挡 | 字号自适应与刘海宽度设置 | 恢复默认宽度，确认最新基线，避免任意加宽刘海 |
| 日历切页闪退 | 是否最新构建、事项数据可解析 | 备份 `calendar-items-v1.json`，收集崩溃日志并回退 |
| 日程/待办不显示 | 日期、筛选、JSON 文件 | 双击对应日期；检查数量标识和持久化文件 |
| 截图录屏无响应 | 屏幕录制权限、磁盘空间 | 在系统设置授权，重启应用，检查输出目录 |
| 麦克风无声 | 麦克风权限与输入设备 | 授权并选择有效输入设备 |
| 快捷键无效 | 是否启用、是否冲突 | 在键盘快捷键页面重新录制或恢复默认 |
| AI 助手不可用 | API Key、模型、网络、服务商响应 | 重新配置；不要把 Key 发给他人或写入日志 |

## 5. 数据路径快速检查

```bash
ls -la "$HOME/Library/Application Support/Atoll/LiveEarnings"
ls -la "$HOME/Pictures/Atoll Screenshots" 2>/dev/null
ls -la "$HOME/Movies/Atoll Recordings" 2>/dev/null
```

这些命令只读。不要用递归删除命令“修复”应用。

## 6. 升级与回归

故障修复后至少验证原问题、相邻流程、应用重启和数据持久化。闪退、数据破坏、权限越界类问题必须补充自动测试或明确的人工回归用例。

## 7. 升级为事故

满足以下任一条件时按事故处理：用户数据丢失、隐私内容被非预期保存或上传、录屏无法停止、API Key 暴露、签名产物被篡改、同一 P1 问题重复出现。事故处理应包含止损、证据保全、影响评估、修复、回滚和复盘。
