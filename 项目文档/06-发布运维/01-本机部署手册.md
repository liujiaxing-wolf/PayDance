# 本机部署手册

## 1. 适用范围

本手册用于把当前源码构建并部署到开发者本人的 Mac。它不产生可公开分发的正式安装包。

## 2. 前置条件

- Apple Silicon、带实体刘海的 MacBook；
- macOS 14.6+；
- 完整 Xcode 已安装并完成首次启动组件安装；
- 源码位于 `/Users/Apple/Desktop/Atoll`；
- 当前分支为经批准的发布分支，工作区无未确认修改。

## 3. 构建前确认

```bash
cd /Users/Apple/Desktop/Atoll
git switch 第二阶段开发最终版
git status --short
git log -1 --oneline
python3 -m unittest discover -s tests -p 'test_*.py'
```

预期基线为 `0efcace` 或其后经过验收的新提交。

## 4. 构建

```bash
xcodebuild \
  -project DynamicIsland.xcodeproj \
  -scheme DynamicIsland \
  -configuration Debug \
  -destination 'platform=macOS' \
  -derivedDataPath /tmp/atoll-local-build \
  build \
  CODE_SIGNING_ALLOWED=NO
```

产物位于：

```text
/tmp/atoll-local-build/Build/Products/Debug/Atoll.app
```

## 5. 临时签名与安装

先退出正在运行的 Atoll。若 `/Applications/Atoll.app` 是唯一可用版本，先手工复制一份备份，再执行：

```bash
pkill -x Atoll 2>/dev/null || true
codesign --force --deep --sign - /tmp/atoll-local-build/Build/Products/Debug/Atoll.app
ditto /tmp/atoll-local-build/Build/Products/Debug/Atoll.app /Applications/Atoll.app
codesign --verify --deep --strict /Applications/Atoll.app
open /Applications/Atoll.app
```

如果系统拒绝写入 `/Applications`，请在 Finder 中将应用拖入“应用程序”，或使用具备该目录写权限的管理员账户。不要为了安装而关闭系统整体安全机制。

## 6. 首次运行

1. 完成实时收益首次配置；
2. 需要截图/录屏时，在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”允许 Atoll；
3. 需要麦克风录制时允许麦克风权限；
4. 若权限状态未刷新，完全退出并重新打开 Atoll；
5. 验证刘海静默金额、Home、工作日历和截图录屏。

## 7. 部署后验收

- 刘海金额完整、不遮挡常用菜单栏图标；
- Home 展开不贴顶、不闪退，原 Atoll 标签可用；
- 设置变更立即反映在金额和进度条；
- 工作日历可双击任意日期并管理事项；
- 截图/录屏文件出现在预期目录；
- 重启后本地配置与事项仍存在。

## 8. 关于权限重置

macOS 权限按签名身份识别。临时签名或替换应用后可能需要重新授权。只有在故障排查且用户明确知情时，才使用 `tccutil reset` 重置指定服务；不要无差别重置全部隐私权限。
