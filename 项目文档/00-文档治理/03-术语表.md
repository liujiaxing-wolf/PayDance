# 术语表

| 术语 | 定义 |
|---|---|
| Atoll | 融合后的唯一 macOS 宿主应用，源代码位于 `/Users/Apple/Desktop/Atoll`。 |
| 薪跳 / PayDance | 原实时工资看板及能力来源，当前不作为融合产品的独立运行外壳。 |
| 实时收益 / Live Earnings | 根据薪资模式、有效工作日程和当前时间计算的预估当日收入。不是工资结算或考勤结果。 |
| 关闭态刘海 | Atoll 未展开时，围绕实体刘海展示的紧凑状态区域。 |
| 展开态 / Home | 鼠标移入或主动打开后显示的 Atoll 完整交互区域。 |
| 工作日历 | 对工作日、休息日、法定节假日、请假、临时工作日及当天时间例外进行管理的界面和规则。 |
| 日程 | 有开始和结束时间的日历事项，可同步到 macOS 日历（取决于权限和实现路径）。 |
| 待办 | 可标记完成/未完成的提醒事项或本地待办。 |
| 日期例外 | 用户对某一天的类型或工作时间进行的手动覆盖。 |
| 有效工作时间 | 扣除非工作时段和启用的午休后，用于实时收益计算的时间。 |
| 截图 | 区域、窗口或内置屏幕的静态图像捕获。 |
| 录屏 | 区域或内置屏幕的视频捕获，可按设置包含系统声音和麦克风。 |
| 内置屏幕 | MacBook 自带显示器。二期不提供多显示器选择。 |
| Defaults | Atoll 使用的偏好存储封装，部分配置保存在用户偏好域。 |
| Keychain | macOS 钥匙串。部分第三方令牌使用 Keychain，但当前 Screen Assistant 的模型 API Key 仍由 Defaults 读取，属于已记录安全债。 |
| ADR | Architecture Decision Record，架构决策记录。 |
| PRD | Product Requirements Document，产品需求文档。 |
| DoD | Definition of Done，完成定义。 |
| SSDF | NIST Secure Software Development Framework。 |
| 本机验收包 | 为当前电脑生成并临时签名的 Debug `Atoll.app`，不是公开发行包。 |
