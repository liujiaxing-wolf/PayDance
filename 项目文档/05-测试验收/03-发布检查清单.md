# 发布检查清单

> 使用方式：每次候选发布复制本清单，填写版本、提交、负责人和证据链接。未勾选项不得默认视为通过。

## 基本信息

- [ ] 版本号：
- [ ] Git 标签：
- [ ] 发布提交：
- [ ] 构建日期：
- [ ] 发布负责人：
- [ ] 验收负责人：

## 范围与文档

- [ ] 最终产品基线与本次范围一致。
- [ ] 需求追踪矩阵覆盖所有变更。
- [ ] CHANGELOG 使用用户可理解的语言记录变更。
- [ ] 已知限制、风险登记册和用户手册已同步。
- [ ] 不在范围内的平台和功能未被误写为支持。

## 代码与质量

- [ ] 工作区干净，发布提交可复现。
- [ ] `git diff --check` 通过。
- [ ] 自动回归全部通过。
- [ ] Debug/Release 构建通过且无新增高风险警告。
- [ ] 真实刘海设备核心冒烟通过。
- [ ] 无未解决 P0/P1 缺陷。
- [ ] 数据迁移、升级和回滚路径已演练。

## 权限、隐私与安全

- [ ] 屏幕录制、麦克风和音频权限文案准确。
- [ ] 拒绝权限时应用不崩溃且给出可执行提示。
- [ ] API Key、证书、私钥和用户数据未进入仓库或日志。
- [ ] API Key 已迁移 Keychain，或风险已被正式接受。
- [ ] ATS 例外已缩小到最小范围。
- [ ] 威胁模型已按本次变更复核。
- [ ] 第三方依赖、NOTICE 和许可证清单已生成并审核。

## 签名与分发

- [ ] 使用项目所有者批准的 Bundle ID、Team 与签名证书。
- [ ] Release 产物签名验证通过。
- [ ] Hardened Runtime 与 entitlements 符合预期。
- [ ] 公证和 stapling 通过。
- [ ] 安装包、版本号、图标和卸载说明正确。
- [ ] 在干净测试账户上安装、首次启动和升级均通过。
- [ ] 发布哈希已记录，下载渠道和回滚产物可用。

## 发布后

- [ ] 核心启动、收益、日历、截图录屏流程复查通过。
- [ ] 崩溃、权限失败和磁盘写入异常监测方案已启用。
- [ ] 支持与故障排查入口可访问。
- [ ] 回滚负责人和停止发布条件已明确。

## 当前基线说明

`第二阶段开发最终版` / `0efcace` 已满足本机验收，但没有满足上述正式签名、公证和公众分发项，因此不能标记为公开生产发布。
