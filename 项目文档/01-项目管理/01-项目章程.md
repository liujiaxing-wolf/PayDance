# Atoll × 薪跳项目章程

## 文档信息

| 项目 | 内容 |
|---|---|
| 版本 | 1.0 |
| 状态 | 已批准（依据用户两阶段验收结论） |
| 日期 | 2026-08-26 |
| 项目类型 | 现有 macOS 产品能力融合与两阶段迭代 |

## 1. 项目使命

将 PayDance 的实时收益能力以原生 Swift/SwiftUI 模块融入 Atoll，把 MacBook 实体刘海变成低打扰的收益、工作日历、日程待办和截图录屏入口，同时保留 Atoll 原有能力。

## 2. 业务目标

1. 用户可选择启用实时收益；关闭后正常使用原 Atoll。
2. 收益数字在关闭态刘海持续可见且不遮挡实体摄像头或常用菜单栏应用。
3. Home 展示金额、状态和绿色进度条。
4. 工作日历支持固定星期、法定节假日、请假、临时工作日和当天时间例外。
5. 日程和待办可以创建、查看、修改、完成和删除，并在月历日期中显示数量标记。
6. 支持内置屏幕截图、录屏、声音控制和可配置快捷键。
7. 薪资、历史和日期例外本地优先保存，不建设账号和云同步。

## 3. 成功标准

- Phase 1 与 Phase 2 均由用户明确验收通过。
- Atoll 是唯一运行宿主，PayDance 的 Vue/Tauri 外壳不进入 macOS 产物。
- 自动回归和 Debug 构建通过。
- macOS 刘海、Home、日历、截图录屏主流程没有阻断问题。
- 项目资料具备统一入口、可追踪需求、发布回滚和安全边界。

## 4. 正式范围

| 维度 | 范围 |
|---|---|
| 平台 | macOS 14.6+ |
| 硬件 | Apple Silicon、带实体刘海的 MacBook |
| 显示器 | 内置屏幕；不支持多显示器选择 |
| 宿主 | Atoll |
| 数据 | 本地配置、本地 JSON、用户选择的截图与录屏文件 |
| 网络 | Atoll 原有网络能力；Screen Assistant 仅在用户配置供应商 Key 并主动发送时联网 |

## 5. 非目标

- Windows、Web、Intel Mac 和无刘海 Mac 的本阶段正式支持。
- 复杂排班、跨夜班、个税、工资结算和考勤系统集成。
- 历史 CSV 导出、账号、云同步和跨设备同步。
- 多显示器捕获、视频剪辑、直播、摄像头画中画。
- App Store 或公开 DMG 发布（需单独取得签名、公证和发布授权）。

## 6. 角色与职责

| 角色 | 责任 |
|---|---|
| 产品所有者（用户） | 决定范围、视觉方向和最终验收；授权发布行为。 |
| 开发维护者 | 设计、开发、测试、文档、构建、缺陷修复和技术风险说明。 |
| Atoll 上游维护者 | 上游许可证、主线架构和公开发行规则的最终决定者；本项目不代表其已接受改动。 |
| 最终用户 | 配置薪资、日历、权限、快捷键和 API Key；对本地数据与录制内容负责。 |

## 7. 约束与假设

- 采用现有 Atoll Xcode 工程和依赖体系。
- 本机缺少原作者团队的 Mac Development 私钥时，只能临时签名验收包。
- macOS 权限由用户在系统设置中授权或撤销，应用无法绕过。
- 法定节假日规则包必须有明确年份覆盖；未覆盖年份回退到固定工作日规则。
- 实时收益是估算展示，不构成劳动、财务或税务凭证。

## 8. 终止与恢复条件

阶段结项后允许停止开发。恢复开发前必须重新核对：当前代码分支、Xcode/macOS 版本、依赖状态、权限 API、风险登记册和文档链接。
