# 已知限制与路线图

## 1. 当前已知限制

| 类别 | 限制 | 用户影响 | 当前处理 |
|---|---|---|---|
| 平台 | 仅正式面向 macOS 刘海 MacBook | 其他平台不保证可用 | 明确范围，不提供伪兼容 |
| 显示器 | 只捕获内置屏幕 | 外接屏不能选择 | 入口禁用或提示范围 |
| 排班 | 不支持夜班、跨夜和复杂轮班 | 非固定白班计算可能不准 | 仅允许日期和当天时间例外 |
| 节假日 | 规则包按年份覆盖 | 未覆盖年份缺少法定判断 | 回退固定星期并允许手动修正 |
| 收益 | 不含个税、加班倍数和实际到手 | 不能用于结算 | 明确标注估算 |
| 历史 | 不提供 CSV/云同步 | 不能跨设备或批量分析 | 本地日周月查看 |
| 录屏 | 不提供剪辑、转码、直播 | 只生成基础录屏文件 | 保持轻量边界 |
| 发行 | 当前为本机临时签名 Debug 包 | 不能作为公众发行包 | 公开发布前走正式签名公证 |
| 密钥 | Screen Assistant Key 通过 Defaults 读取 | 本地保护弱于 Keychain | 不写日志；列入安全加固 |
| 网络 | Info.plist 允许任意加载 | 网络边界较宽 | 列入 ATS 收缩工作 |

## 2. 下一阶段候选优先级

### P0：发布准备

- Developer ID 签名、公证、DMG 和升级源验证。
- API Key 迁移到 Keychain并完成旧值清理。
- 收缩 ATS，形成允许域名清单。
- 长时录屏、磁盘不足、睡眠/唤醒和权限运行中撤销测试。

### P1：质量增强

- 更完整的 macOS 版本与刘海尺寸矩阵。
- 日历/提醒事项同步状态和冲突提示。
- 节假日规则包更新与签名校验流程。
- 捕获文件管理、存储占用提示和恢复中心。

### P2：产品增强（需新 PRD）

- 更灵活的排班模板。
- 可选历史导出。
- 更细粒度的收益目标和复盘。

### 暂不建议

- Windows/Web 对等版本、多显示器、云账号、工资税务和完整视频编辑。这些会显著扩大产品、隐私和运维边界，必须作为独立项目评估。

## 3. 路线图准入规则

候选项进入开发前必须回答：用户问题、目标平台、数据来源、权限、失败降级、存储迁移、测试矩阵、发布影响和退出策略。仅凭“功能看起来有用”不得直接进入代码。
