# 用户使用手册

## 1. 适用环境

- Apple Silicon、带实体刘海的 MacBook。
- macOS 14.6 或更高版本。
- 当前本机应用：`/Applications/Atoll.app`。

## 2. 第一次启动

1. 打开 Atoll。
2. 在首次引导中选择是否启用“实时收益”。
3. 若启用，默认选择“月薪”，填写金额、币种、工作日、上班和下班时间。
4. 根据需要开启午休暂停并设置时间。
5. 完成配置；不想使用可跳过，之后在“设置 → 实时收益”重新开启。

实时收益是估算值。请按税前/税后或实际口径自行统一输入，应用不会替你计算个税。

## 3. 查看实时收益

- 未展开时，实体刘海右侧显示无货币符号数字。
- 鼠标移入刘海后进入 Home，可查看金额、状态、绿色进度条和今日百分比。
- 设置工作结束时间、薪资或午休后，Home 应立即刷新。
- 若不想展示，关闭实时收益或开启隐私模式。
- 刘海数字颜色可在“设置 → 实时收益 → 外观”修改；Home 进度条固定为绿色。

## 4. 使用工作日历

1. 点击顶部日历标签进入“工作日历”。
2. 单击日期选中它。
3. 双击任意日期打开“日程与待办”面板，即使当天还没有事项也可以打开。
4. 使用“添加日程”或“添加待办”创建事项。
5. 有事项的日期会在日期卡片下方显示蓝色日程或橙色待办数量。

### 修改或删除事项

1. 双击对应日期。
2. 在列表中点击铅笔修改标题或时间。
3. 待办可切换完成/未完成。
4. 点击垃圾桶删除单项；删除前确认。
5. “清空全部”会删除应用管理的全部日程和待办，必须二次确认。

### 修改日期类型

选中日期后，可设置请假、临时工作日或当天工作时间。恢复自动判断后，应用重新使用官方规则包或固定星期规则。

## 5. 查看收益历史

在 Home 实时收益卡点击“历史”。可按日、周、月查看二期启用后的记录。清除历史只删除历史记录，不应删除当前薪资设置。

## 6. 截图与录屏

Home 的“截取与录制”区域提供：

- 区域、窗口、屏幕截图；
- 区域和全屏录制；
- “键盘快捷键”入口。

首次使用时 macOS 会请求“屏幕与系统音频录制”。开启麦克风录制时还会请求麦克风权限。拒绝麦克风后仍可尝试只录画面/系统声音，具体以错误提示为准。

默认目录：

- 截图：`~/Pictures/Atoll Screenshots`；
- 录屏：`~/Movies/Atoll Recordings`。

录制中刘海显示红点和计时。点击停止按钮或配置的停止快捷键结束录制。

## 7. 配置截图录屏快捷键

1. 在 Home 的“截取与录制”卡片点击“键盘快捷键”，或进入设置中的截图录屏页面。
2. 选择动作并按下新的组合键。
3. 若组合与其他 Atoll 捕获动作重复，系统拒绝保存；请换一个组合。
4. 修改自动生效，无需额外“保存”。

## 8. 配置 AI 助手

AI 助手属于 Atoll 原有能力。选择 OpenAI 模型时：

1. 在 OpenAI Platform 由本人创建 API Key。
2. 只把 Key 粘贴到 Atoll 的配置框，不要发到聊天、截图或 Git。
3. 保存配置后主动发送消息才会调用供应商服务。
4. ChatGPT/Codex 登录和订阅不是 API Key；API 用量由供应商账户单独管理。

当前版本的 API Key 存储保护仍有改进空间。共享电脑上不建议长期保存高权限 Key；可以创建受限项目 Key并定期轮换。

## 9. 常见问题

- **金额不变化**：确认今天是工作日且在有效工作时段；检查请假/休息和午休设置。
- **日历面板打不开**：先单击选中日期，再双击；若仍失败，重启 Atoll。
- **截图录屏无权限**：系统设置 → 隐私与安全性 → 屏幕与系统音频录制，允许 Atoll 后重启。
- **麦克风没有声音**：检查麦克风权限和 Atoll 设置中的麦克风开关。
- **快捷键没反应**：检查冲突，换用更少被系统占用的组合。
- **应用无法打开**：本机验收包可能需要重新临时签名或重新部署，见部署手册。
