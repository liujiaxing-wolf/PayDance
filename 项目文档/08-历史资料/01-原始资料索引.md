## 6. 资料归档规则

- 原 PRD、技术声明和验收清单只追加更正说明，不覆盖历史结论；
- 当前产品状态统一写入 `项目文档/02-产品需求/01-最终产品基线.md`；
- 新阶段建立新版本文档并在本索引登记；
- 删除或迁移资料前先确认 Git 已跟踪且链接已更新；
- 含个人信息、API Key 或真实录屏的材料不得进入 Git 归档。
