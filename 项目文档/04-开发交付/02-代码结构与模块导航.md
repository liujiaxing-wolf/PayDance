## 5. 修改导航

- 金额公式错误：先看 Engine 和 Resolver，不在 View 打补丁。
- 设置后不刷新：看 Controller 的 Defaults publisher 和 snapshot 刷新。
- 月历布局/双击/事项标记：看 WorkCalendarViews。
- 数据丢失：看对应 Store 的 schema、revision 和原子写入。
- 录屏闪退或无法停止：看 RecordingCoordinator 状态机和回调线程。
- 文件未保存：看 CaptureFileStore 的书签、临时文件和 finalize。
- 刘海遮挡：看 LiveEarningsLayout 和关闭态布局，不通过扩大窗口解决。
- 页面切换元素闪现：确保整页内容处于同一个转场容器，避免独立 overlay。

## 6. 不变量

1. Atoll 原功能不能被新的互斥 `if/else` 分支整体替换。
2. 收益计算只由 Engine 输出。
3. 日期键使用 `LocalDate`，不要直接用包含时区的 `Date` 当日键。
4. Store 不能在主线程做频繁文件写入。
5. 捕获服务只处理内置屏幕，除非新 PRD 明确改变范围。
6. API Key、工资、事项正文和录制内容不得进入日志或测试夹具。
