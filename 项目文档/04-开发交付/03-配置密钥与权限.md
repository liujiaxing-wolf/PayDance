# 配置、密钥与权限

## 1. 配置分类

| 配置 | 当前存储 | 敏感性 | 处理要求 |
|---|---|---|---|
| 实时收益设置 | Defaults `liveEarningsConfig.v1` | 高 | 不记录值；只在本地使用 |
| 捕获偏好 | Defaults `capturePreferences.v1` | 中 | 目录书签按安全作用域访问 |
| 快捷键 | KeyboardShortcuts/Defaults | 低 | 检查重复和系统冲突 |
| OpenAI/Gemini/Claude/Groq Key | Defaults | 极高 | 不提交、不回显、不记录；建议迁移 Keychain |
| Spotify OAuth Token | Keychain | 高 | 延续 Keychain 存储和迁移逻辑 |
| Sparkle 公钥 | Info.plist | 公共验证材料 | 可以提交；不是私钥 |

## 2. API Key 使用规范

- API Key 由用户在供应商控制台创建，应用不能替用户推断或展示账户中的旧 Key。
- ChatGPT/Codex 订阅不是 OpenAI API Key。
- Key 只粘贴到应用配置框，不发到聊天、Issue、截图、日志或 Git。
- 建议使用项目级、可撤销、额度受限的 Key，并定期轮换。
- 发现泄露时立即在供应商控制台吊销，生成新 Key，再清理本机配置和历史输出。

### 当前安全债

代码在 `models/Constants.swift` 中定义 API Key Defaults，并由 Screen Assistant 读取。正式发布建议：

1. 新 Key 写入 Keychain；
2. 回读确认成功；
3. 清除 Defaults 旧值；
4. 保留一次性迁移标记；
5. 任何错误信息不得包含 Key 或完整鉴权头。

## 3. macOS 权限矩阵

| 权限/能力 | 用途 | 触发时机 | 拒绝后的降级 |
|---|---|---|---|
| 屏幕与系统音频录制 | 截图、录屏、系统声音 | 用户首次捕获 | 禁用对应捕获并给出设置入口 |
| 麦克风 | 录屏包含环境声音 | 用户开启麦克风录制 | 继续无麦克风录制或提示取消 |
| 日历 | 查看/创建日程 | 用户进入或创建日程 | 日历事项不可用，收益基础规则仍可用 |
| 提醒事项 | 创建和管理待办 | 用户使用待办 | 待办不可用，日程和收益不受影响 |
| 辅助功能 | Atoll 原有系统控制/交互 | 使用相关原能力 | 只影响依赖该权限的功能 |
| Apple Events | 控制 Music/Spotify/Notes 等 | 用户启用对应集成 | 对应集成降级 |
| 摄像头/音频输入 entitlement | Atoll 原有或媒体能力 | 对应功能启用 | 对应功能降级 |

## 4. Info.plist 与 Entitlements 审查

当前已包含：

- `NSScreenCaptureUsageDescription`
- `NSAudioCaptureUsageDescription`
- `NSMicrophoneUsageDescription`
- 日历、音频输入、摄像头和 Apple Events entitlement
- `NSAllowsArbitraryLoads = true`

`NSAllowsArbitraryLoads` 是开放风险。公开发布前应盘点实际端点并使用最小 ATS 配置，避免所有请求默认放行。

## 5. 日志规则

允许记录：错误类型、状态机阶段、权限布尔状态、文件扩展名、非敏感计数和耗时。

禁止记录：API Key/Token、薪资金额、日历/待办标题、聊天正文、截图像素、录音内容、完整用户路径和鉴权响应。

## 6. Git 与本地环境

- 不创建包含真实 Key 的 `.env` 示例。
- 若未来引入环境文件，提交 `.env.example` 只包含占位符，并把真实文件加入 `.gitignore`。
- 提交前运行仓库的 secrets 检查；发现疑似密钥只报告文件位置，不在终端或聊天中打印完整值。
