## 文档优先级

资料冲突时按以下顺序处理：

1. 用户最新、明确确认的需求和验收结论；
2. 本目录中的最终产品基线、需求追踪矩阵和架构决策；
3. Phase 2 PRD、技术适配声明和开发手册；
4. Phase 1 PRD、技术适配声明和开发手册；
5. Atoll 原始文档与 PayDance 原始文档；
6. 通用 Vibe Coding 手册。

任何新需求都不得只改代码。至少同步更新最终产品基线、需求追踪矩阵、相关架构或安全文档、测试用例和变更记录。
